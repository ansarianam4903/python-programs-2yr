## Requirements
- Python 3.x
- NumPy

## Installation
Clone this repository:
```bash
git clone https://github.com/ANSARIANAM4903/Python-Programs-2yr.git
```

Open the project folder:
```bash
cd Python-Programs-2yr
```

Install NumPy:
```bash
pip install numpy
```

## How to Run
Run any Python program using:
```bash
python filename.py
```
For example:
```bash
python : number even or odd.py
```
